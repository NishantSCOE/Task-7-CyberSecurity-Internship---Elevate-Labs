# Elevate Labs Internship - Task 7: Browser Extension Security Audit

This repository contains the deliverables for Task 7 of the Elevate Labs Cybersecurity Internship. The task focuses on the security risks of browser extensions and the process for auditing and removing them.

### **Objective**
To learn how to spot and remove potentially harmful browser extensions by reviewing their permissions and functionality.

### **Files in this Repository**
* `report.md`: A detailed report documenting the audit process, findings, actions taken, and research on extension security.
* `screenshots`: A folder containing before-and-after images of the browser's extension list and details of specific extension permissions.

### **Process Overview**
1.  Opened the browser's extension manager to review all installed extensions.
2.  Carefully checked the permissions and reviews for each extension.
3.  Identified and removed suspicious or unnecessary extensions.
4.  Researched how malicious extensions can harm users.
5.  Documented the entire process and findings in a report.

### **Key Concepts Covered**
* Browser Security
* Extension Permissions
* Malware
* Security Best Practices
